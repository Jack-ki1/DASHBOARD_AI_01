# Routes

This is a **Vite SPA** using TanStack Router file-based routing. Every `.tsx`
file in this directory defines a page. `routeTree.gen.ts` is auto-generated by
`@tanstack/router-plugin/vite` — don't edit it by hand.

## Conventions

| File            | URL                                          |
| --------------- | -------------------------------------------- |
| `index.tsx`     | `/`                                          |
| `about.tsx`     | `/about`                                     |
| `users/$id.tsx` | `/users/:id` (dynamic)                       |
| `__root.tsx`    | app shell (providers, `<Outlet />`, toaster) |

There is no server code here: pages call the backend over REST via
`src/lib/api.ts`. Page titles use the `useTitle` hook. There is no
`src/pages/` directory and no SSR.
